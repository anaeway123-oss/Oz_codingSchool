# 7일차 프론트엔드 연동 및 앱 실행 화면

## 1. 개요
* 본 문서는 FastAPI 백엔드 API와 SPA(Single Page Application) 프론트엔드 UI의 실제 연동 상태 및 실행 흐름을 정리한 문서입니다.
* 6일차 폐렴 예측 AI 기능(`SimpleCNN`) 및 각 화면별 API 호출 플로우를 실제 코드 기준으로 대조하여 명세합니다.

---

## 2. 페이지별 UI 및 API 연동 흐름

### 1) 회원가입 및 로그인
* **관련 템플릿:** `signup.html`, `login.html`
* **연동 API:**
  * `POST /api/v1/users/` (회원가입)
  * `POST /api/v1/auth/login` (로그인 - JWT Bearer 토큰 발급)
* **프론트엔드 동작:**
  * 사용자 계정 정보(이메일, 비밀번호, 이름, 부서, 역할 등)를 입력받아 인증을 수행합니다.
  * 로그인 성공 시 전달받은 토큰(`state.token`)을 브라우저에 저장하고 환자 목록 화면(`/patients`)으로 라우팅합니다.
* **실행 화면:**
  * `docs/images/day7_01_login.png` *(추가 예정)*

---

### 2) 환자 관리 (목록 조회 및 신규 등록)
* **관련 템플릿:** `patients.html`, `patient-create.html`
* **연동 API:**
  * `GET /api/v1/patients/` (환자 목록 조회)
  * `POST /api/v1/patients/` (환자 등록)
* **프론트엔드 동작:**
  * 등록된 환자 리스트를 테이블 형태로 렌더링합니다.
  * 신규 환자 등록 폼을 통해 이름, 성별, 생년월일, 주민번호 등의 정보를 입력받아 저장합니다.
* **실행 화면:**
  * `docs/images/day7_02_patients.png` *(추가 예정)*

---

### 3) 환자 상세 및 진료기록(X-ray 업로드)
* **관련 템플릿:** `patient-detail.html`, `record-create.html`
* **연동 API:**
  * `GET /api/v1/patients/{patient_id}` (환자 상세 정보 조회)
  * `POST /api/v1/patients/{patient_id}/medical-records` (진료기록 및 X-ray 파일 업로드)
* **프론트엔드 동작:**
  * 특정 환자의 기본 정보와 이전 진료 기록 이력을 확인합니다.
  * 새로운 흉부 X-ray 이미지 파일과 증상(symptoms) 텍스트를 멀티파트 폼(`multipart/form-data`)으로 백엔드에 전송하여 저장합니다.
* **실행 화면:**
  * `docs/images/day7_03_record_create.png` *(추가 예정)*

---

### 4) 진료기록 상세 및 AI 폐렴 예측 (핵심 연동)
* **관련 템플릿:** `record-detail.html`
* **연동 백엔드 API:**
  * `GET /api/v1/patients/{patient_id}/medical-records/{record_id}/ai-predictions` (저장된 예측 결과 조회)
  * `POST /api/v1/patients/{patient_id}/medical-records/{record_id}/ai-predictions` (AI 폐렴 예측 실행)
* **프론트엔드 UI 동작 및 흐름:**
  1. 진료기록 상세 페이지 로드 시 등록된 X-ray 이미지(`xray-img`)와 기존 예측 결과(`analysis-list`)를 렌더링합니다.
  2. 사용자가 **[AI 예측 결과보기]** (`#predict-btn`) 버튼을 클릭하면 `pages.js`의 `handlePredict(recordId)` 핸들러가 트리거됩니다.
  3. API 요청을 통해 AI 추론(`SimpleCNN`)이 수행되며, 캐시된 데이터가 있을 경우 기존 결과를 반환합니다.
  4. 응답 결과를 바탕으로 수행 일시, 판독 결과(**Positive/Negative**), 신뢰도(**Confidence %**), 사용 모델(**SimpleCNN**)을 화면 테이블에 동적으로 렌더링합니다.
  5. 성공 시 `utils.showAlert('AI 예측이 완료되었습니다.', 'success')` 알림을 출력하고 화면을 새로고침합니다.
* **실행 화면:**
  * `docs/images/day7_04_ai_prediction.png` *(추가 예정)*

### 5) 마이페이지 및 사용자 관리 (관리자)
* **관련 템플릿:** `my-page.html`, `admin-users.html`
* **연동 API:**
  * `GET /api/v1/mypage/` (내 정보 조회)
  * `GET /api/v1/users/` (전체 유저 목록 조회 - 관리자 권한)
* **프론트엔드 동작:**
  * 로그인한 사용자 본인의 프로필 정보를 확인 및 수정합니다.
  * 관리자(Admin) 권한을 가진 계정의 경우 전체 유저 목록 조회 및 권한 관리 화면을 렌더링합니다.
